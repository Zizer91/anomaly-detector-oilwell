# 🛢️ Anomaly Detector for Oil Well

Детектор аномалий для нефтяных скважин на основе Isolation Forest.  
Обучается только на нормальных данных и находит выбросы (аномалии) во временных рядах.

## 🎯 Задача

Обнаружение **быстрой потери продуктивности** скважины по данным давления и температуры.

## 📊 Результаты

- **Модель:** Isolation Forest
- **Параметры:** window_size=120, step=30, contamination=0.1
- **Признаки:** давления и температуры (6 параметров)
- **Метрики:** F1-score = 0.985, Recall = 1.000, Precision = 0.971
